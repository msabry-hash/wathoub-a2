# وثوب ١ · مشروع A2

موقع تفاعلي لمشروع **وثوب ١** (مشروع A2) في حي القيروان، الرياض: 248 شقة في 8 مبانٍ، مع المخططات والمرافق والتصميم الداخلي والواجهات.

**الرابط المباشر:** https://msabry-hash.github.io/wathoub-a2/

## تحديث حالات الوحدات
عدّل ملف `status.js` فقط، مثلًا:

```js
const STATUS = {
  "A101": "available",  // متاحة
  "A102": "reserved",   // محجوزة
  "B305": "sold",       // مباعة
};
```

بعد الحفظ تظهر الحالة على بطاقة الوحدة وعلى المخطط، ويظهر فلتر الحالة تلقائيًا. التراسات الـ31 تظهر دائمًا "غير متاحة".

## الملفات
- `index.html`, `style.css`, `app.js`: الصفحة والتصميم والتفاعل
- `project-data.js`: بيانات الوحدات والمرافق وروابط Drive
- `floor-plans.js`: مخططات الأدوار ومواقع الوحدات عليها
- `plans/`: مخططات الوحدات · `img/`: المساقط والصور · `fac/`: المرافق · `ext/`: الواجهات
